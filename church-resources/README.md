# 로그인 후 사용하는 교회 자료

사용자가 제공한 자료에서 선별한 폰트 30종, 템플릿 37개 파일의 196개 슬라이드, 개역개정 66권·1,189장·31,103절, 금요예배 이미지 20개입니다. 원본 문서 ZIP과 성경 등록 정보는 포함하지 않습니다. 폰트는 필요한 PostScript 이름만 TTC에서 추출해 WOFF2로 변환했습니다. 성경과 템플릿 JSON은 gzip으로 보관하고 빌드 시 복원합니다. PSD는 브라우저 미리보기용 PNG로 변환했으며 문서 안의 원래 경로는 유지합니다.

`catalog.json`이 지정한 파일만 빌드합니다. Worker는 `/resources/*`의 세션을 확인하고 `private, no-store`로 제공합니다. Cloudflare의 `run_worker_first` 설정에서 모든 요청이 Worker를 거치도록 유지해야 합니다. 다른 위치의 같은 이름 파일은 자동 대체하지 않습니다. 템플릿이 참조하는 미업로드 이미지와 기존 누락 미디어는 연결 필요 표시를 유지합니다.

`expectedDocuments: 3107`은 이번 최초 업로드 계획 기준 수이며 서버의 실제 전체 수를 제한하지 않습니다. 재업로드 버전은 현황판 문서 수에 중복 집계하지 않습니다.
