# Sync 0.6.5: 기록 초기화와 충돌 비교

사용자는 2026-10-03 서버를 비웠고, 정리한 Mac 문서는 약 2,885개라고 보고했다. 기존 앱은 과거 기준 경로까지 합산해 3,109개(충돌 3,107/보내기 2)를 표시했다. 서버 기록 삭제는 Mac의 비교 기준 삭제가 아니었다.

- 도구 → **동기화 기록 초기화…**: 현재 문서 폴더/서버 조합의 활성 프로필을 새 세대로 전환한다. 문서·재생목록 비교 및 미디어 재개 키가 새 기준을 사용한다. 이전 기록과 백업은 비활성 폴더에 격리 보관하며 로컬 문서/이미지·서버 자료·로그인은 보존한다. 실제 파일 복구가 중단된 상태와 PP6 실행 중 초기화는 거절한다. 세대 포인터는 원자적으로 저장한다.
- 양쪽에 실물이 없는 과거 기준 경로는 일반 비교 개수에서도 제외한다.
- 빈 서버 재구축: PP6 종료 → 설정의 최종 문서 폴더/재생목록 확인 → 기록 초기화 → 비교 완료 → 이 Mac 기준으로 서버 다시 맞추기 → 확인창의 현재 개수 확인·반영 → 이미지 전송 대상 확인 → 이미지 서버 전송. 이미지 경로 변경은 문서를 먼저 다시 올린 다음 새로 이미지 점검한다. 보관 7개 처리는 재구축 확인 후 마지막이다.
- 문서 충돌창: 슬라이드 대응 목록, Mac/서버 근사 미리보기, 선택 가능한 양쪽 본문·참조 경로·서식 정보. 줄 단위 추가는 초록 +, 삭제는 빨강 −로 표시한다. 그룹 전체 추가/삭제와 서버에 없는 문서도 표시한다. 미리보기는 PP6 실제 렌더와 동일함을 보장하지 않으며 없는 미디어는 자리표시자로 표시한다. 문서 버전 선택/백업/CAS는 기존 적용 경로를 사용한다.
- D1: 초기화는 로컬 기록 변경이며 이후 기존 전체 비교 1회를 사용한다. 비교창은 기존처럼 선택 문서 1개만 다운로드한다. 미디어 세대 변경 후 최초 전송은 현재 대상 hash 존재 확인/문서 참조 연결을 다시 수행한다. 새 대기 폴링·서버 초기화·전체 쓰기를 추가하지 않는다. 운영 비용 실측은 미실행이다.
- 검증: 기존 Native/Core/GUI/Worker 묶음에 초기화 범위·중단 복구 보호·기록만 남은 경로 집계·시각적 추가/삭제와 양쪽 미리보기 합성 캡처를 추가한다. Mac Actions 결과는 이 변경의 검증 실행을 확인한다. 교회 High Sierra 실기는 별도다.
