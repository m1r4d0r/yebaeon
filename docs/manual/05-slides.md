## 세 가지 보기

| 탭 | 단축키 | 쓰는 때 |
|---|---|---|
| 슬라이드 | | 장을 한눈에 보고 순서를 바꿀 때 |
| 리플로우 | <kbd>Alt R</kbd> | 가사를 글로 쭉 보며 줄을 나누고 합칠 때 |
| 편집기 | <kbd>Alt E</kbd> | 글상자 위치·크기·글꼴을 고칠 때 |

![편집기. 글상자를 고르면 오른쪽에 글꼴·크기·정렬이 나와요](img/editor.png)

## 글 고치기

- 편집기에서 글상자를 **두 번 눌러** 고쳐요. 끌어서 옮기고, 모서리로 크기를 바꿔요.
- 휴대폰에서는 글상자를 한 번 눌러 고른 다음 움직여요.
- 오른쪽 칸에서 글꼴·글자 크기·색·정렬·위치를 숫자로 고칠 수 있어요.
- 리플로우에서 <kbd>Alt Enter</kbd>는 장 나누기, 맨 앞에서 <kbd>Backspace</kbd>는 앞 장과 합치기예요.

![리플로우. 가사를 글로 쭉 보며 장을 나누고 합쳐요](img/reflow.png)

## 장 순서·복제

![슬라이드를 끄는 중. 파란 줄과 ‘3번으로’가 들어갈 자리예요](img/slides-drag.png)

- 슬라이드를 끌면 들어갈 자리에 파란 줄과 `n번으로`가 보여요.
- 마지막 장 뒤 빈 곳에 놓으면 문서 맨 끝으로 가요.
- 장을 고르고 <kbd>Ctrl D</kbd>(Mac <kbd>⌘ D</kbd>)로 복제해요.
- 슬라이드를 오른쪽 클릭하면 빠른 편집·이름 바꾸기·복제·복사·붙여넣기·삭제와 배경 메뉴가 나와요.
- 휴대폰·태블릿은 0.3초 누른 뒤 끌어요. 바로 밀면 화면이 스크롤돼요.

## 휴대폰에서 여러 장 고르기·새 장 추가

- 위쪽 보기를 **슬라이드**로 바꾸고 **☑(여러 장 고르기)**를 누른 뒤 원하는 장들을 탭해요. 다시 탭하면 선택이 해제돼요. ☑를 다시 누르면 선택 모드가 끝나요.
- **＋**는 선택한 장 뒤에 새 장을 추가해요. 글상자가 없는 악보·이미지 장에서도 기본 글상자가 있는 빈 장이 만들어져요. 악보 이미지는 새 장에 복사하지 않아요.

## 가사찬양 추가

상단 주보·PPT 옆의 [[가사찬양 추가]](음표 아이콘)에서 제목과 가사를 입력하세요. 빈 줄을 넣은 곳에서만 슬라이드를 나누고, 첫 부분은 제목 슬라이드가 됩니다. 한 부분에 세 줄 이상 입력해도 그대로 한 장에 들어가요. 줄 끝 공백과 처음·끝의 빈 줄은 자동으로 제거됩니다. 하단 미리보기는 옆으로 밀어 확인하세요.

기본은 **찬양 · 기본텍스트/110** 서식에 **배경 없음**이에요. 템플릿은 변경할 수 있고, 입력과 선택은 실행취소·다시 실행 버튼 또는 Ctrl/⌘+Z, Ctrl/⌘+Shift+Z(Ctrl+Y)로 되돌릴 수 있어요. 만든 문서는 서버에 저장되고 편집 화면에서 열려요. 현재 예배 순서에도 추가했다면 그 순서 변경은 서버 저장으로 확정하세요.
