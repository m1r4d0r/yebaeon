## 정리 창

Sync 2 오른쪽 위 `확인 필요 n · 정리 열기`. 종류별 버튼으로 정리하고, 처리하면 다음 줄로 이어져요. 그림 정리용 [[그림 가져오기]]와 [[번호 사본 지우기]]도 여기 있어요.

## 재생목록 순서 덮어쓰기

Mac Sync에서 예배 줄을 오른쪽 클릭하고 **재생목록을 서버 순서로 덮어쓰기…** 또는 **재생목록을 Mac 순서로 덮어쓰기…**를 고르세요. 선택한 예배의 구성·순서·이름만 교체합니다. 문서 본문과 이미지는 바뀌지 않아요. 서버 순서를 받을 때는 PP6를 종료해야 하며, Mac의 이전 순서는 백업하고 마지막 적용 되돌리기로 복구할 수 있어요.

## 문서별 강제 동작

예배 줄을 오른쪽 클릭: 차이 보기 · 서버 것 받기 · Mac 것 올리기 · 서버 휴지통 · Mac에서 지우기 · 웹에서 보기.

**Mac에서 지우기**로 지운 문서는 일반 적용으로 다시 받지 않아요. 복구하려면 정리 창 또는 오른쪽 클릭에서 **서버 것 받기**를 직접 고르세요. 서버 휴지통 문서는 먼저 웹 휴지통에서 꺼내야 합니다.

## 교회 Mac 원격 지원

- Studio 오른쪽 위 작업자 메뉴 › **교회 Mac** 줄에 Sync가 올린 요약과 보고 시각이 보여요. 지난 동기화 기록은 **서버 현황**의 Sync 기록에서 봐요.
- 문제가 생기면 교회 Mac 앞에서 Sync 창의 도구 메뉴 › **원격 지원 시작…**을 눌러 달라고 하세요. 60분 동안 열려요. Mac 쪽에서는 비밀번호를 묻지 않아요.
- 열리면 교회 Mac 창에 Sync 2 본창과 같은 표가 나와요. 체크한 예배를 [[N개 받기·올리기]], 줄을 오른쪽 클릭하면 문서별 강제 동작, [[확인 필요 · 정리 열기]]로 정리 창 버튼, [[전체 확인]] · [[마지막 적용 되돌리기]] · 안내 보내기. 명령에는 관리자 비밀번호가 필요해요(하루 유지).
- Mac은 10초 안팎으로 명령을 가져가 실행하고 결과를 **명령 기록** 탭에 남겨요. Mac 파일을 바꾸는 일은 PP6가 켜져 있으면 하지 않아요.
- 지원은 Mac의 [[끝내기]], 교회 Mac 창의 [[지원 끝내기]], 60분이 지나면 끝나요.

## 되돌리기와 업데이트

- 도구 메뉴 › **마지막 적용 되돌리기…**: 가장 최근 적용 하나만 되돌릴 수 있어요.
- 새 버전이 있으면 노란 줄에 [[지금 설치]]가 나와요. 설치는 누를 때만 해요.
