## 정리 창

Sync 2 오른쪽 위 `확인 필요 n · 정리 열기`. 종류별 버튼으로 정리하고, 처리하면 다음 줄로 이어져요. 그림 정리용 [[그림 가져오기]]와 [[번호 사본 지우기]]도 여기 있어요.

## 문서별 강제 동작

예배 줄을 오른쪽 클릭: 차이 보기 · 서버 것 받기 · Mac 것 올리기 · 서버 휴지통 · Mac에서 지우기 · 웹에서 보기.

## 되돌리기와 업데이트

- 도구 메뉴 › **마지막 적용 되돌리기…**: 가장 최근 적용 하나만 되돌릴 수 있어요.
- 새 버전이 있으면 노란 줄에 [[지금 설치]]가 나와요. 설치는 누를 때만 해요.
