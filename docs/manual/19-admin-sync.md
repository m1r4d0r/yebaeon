## 정리 창

Sync 2 오른쪽 위 `확인 필요 n · 정리 열기`. 종류별 버튼으로 정리하고, 처리하면 다음 줄로 이어져요. 그림 정리용 [[그림 가져오기]]와 [[번호 사본 지우기]]도 여기 있어요.

## 문서별 강제 동작

예배 줄을 오른쪽 클릭: 차이 보기 · 서버 것 받기 · Mac 것 올리기 · 서버 휴지통 · Mac에서 지우기 · 웹에서 보기.

## 교회 Mac 현황과 원격 지원

- Studio 오른쪽 위 이름 메뉴 › **교회 Mac**: Sync가 올린 현황(받을·올릴 예배, 정리 창 목록, PP6 켜짐, 마지막 오류)을 누구나 볼 수 있어요.
- 문제가 생기면 교회 Mac 앞에서 Sync의 **원격 지원 시작…**(메뉴 막대 예배온 메뉴 또는 도구 메뉴)을 눌러 달라고 하세요. 30분 동안 열려요.
- 그동안 현황 창에서 [[다시 비교]] · [[적용]] · 정리 창 버튼 · 문서 강제 동작 · [[마지막 적용 되돌리기]] · 안내 보내기를 할 수 있어요. 관리자 비밀번호가 필요해요.
- Mac은 10초 안팎으로 명령을 가져가 실행하고 결과를 기록에 남겨요. Mac 파일을 바꾸는 일은 PP6가 켜져 있으면 하지 않아요.
- 지원은 Mac의 [[끝내기]], 현황 창의 [[지원 끝내기]], 30분이 지나면 끝나요.

## 되돌리기와 업데이트

- 도구 메뉴 › **마지막 적용 되돌리기…**: 가장 최근 적용 하나만 되돌릴 수 있어요.
- 새 버전이 있으면 노란 줄에 [[지금 설치]]가 나와요. 설치는 누를 때만 해요.
