## 주중 (집이나 휴대폰)

1. **주보 받기** — [[주보로 준비]] → [[!드롭박스에서 가져오기]]에서 이번 주 HWP를 [[!가져오기]]. 자세한 건 [주보로 준비](#bulletin).
2. **노란 칸 검수** — 찬양·기도자·설교 제목·본문·대지·성경 구절이 채워져 있어요. 맞는지 보고 찬양만 쓸 문서를 골라요.
3. **적용 → 서버 저장** — [[!적용]]은 Studio에만 넣어요. 위쪽 [[!서버 저장]]까지 눌러야 끝이에요.
4. **새 악보** — 새 곡이 있으면 [[PPT·PDF 가져오기]]로 악보 PPT를 넣어요. 누르는 순간 서버에 저장돼요.
5. **목사님 설교 PDF** — [[PPT·PDF 가져오기]] → 기존 문서 교체 → `주일예배말씀 목사님 ppt`.

## 주일 아침 (교회 Mac)

1. 교회 Mac을 켜면 Sync 2가 저절로 열려요.
2. 체크된 예배와 받을 문서 이름을 확인하고 [[!N개 받기]].
3. 그다음 ProPresenter를 켜요.

> [!WARNING]
> 받기 전에 ProPresenter를 켜 두었다면 먼저 닫아 주세요. ProPresenter가 켜져 있으면 받기 버튼이 눌리지 않아요.
