| 하고 싶은 것 | 어디서 |
|---|---|
| 이름 바꾸기 | 순서 항목 ⋯ 또는 위쪽 문서 제목 |
| 문서 복제 | 순서 항목 ⋯ (원본 바로 뒤에 들어가요) |
| 저장 이력 보기 | 위쪽 문서 제목 › 작업 이력 |
| 휴지통으로 | 위쪽 휴지통 아이콘, 또는 순서 항목 오른쪽 클릭의 빨간 메뉴 |
| 휴지통에서 꺼내기 | 위쪽 휴지통 › 꺼내기 |

![휴지통 창. 꺼내기는 누구나, 비우기는 관리자만](img/bins.png)

## 보관함과 휴지통은 달라요

- **보관함**: 지금은 안 쓰지만 남겨 둘 것. 일반 검색에서 빠져요. 교회 Mac 파일은 그대로예요.
- **휴지통**: 지울 것. 교회 Mac에서도 Sync 2의 받기 때 macOS 휴지통으로 옮겨요.
- 진짜 삭제는 관리자의 [휴지통 비우기](#admin-trash)뿐이에요.
