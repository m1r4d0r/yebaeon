## 서버 저장

![고친 것이 있으면 서버 저장 옆에 개수가 보여요](img/savebar.png)

- [[!서버 저장]](<kbd>Ctrl S</kbd>)은 이 탭에서 저장하지 않은 **모든 문서와 순서**를 한꺼번에 올려요. 옆에 `문서 2 · 순서 1 수정`처럼 개수가 보여요.
- 저장 전 작업은 브라우저에 초안으로 남아서, 새로 고쳐도 사라지지 않아요.
- 손으로 고친 재생목록에서 다른 재생목록으로 가면 ‘저장하고 넘어갈까요?’를 물어요.

## 누가 먼저 저장했을 때

| 무엇 | 어떻게 되나요 |
|---|---|
| 문서 | 저장을 멈추고 고르게 해요: **최신 불러오기**(내 편집 버림) · **사본으로 저장**(원래 문서 바로 아래에 넣음) · **나중에** |
| 순서 | 내 순서로 저장하고, 그쪽에서 넣거나 뺀 항목을 결과 창으로 알려 줘요 |

## 되돌리기

- 실행취소 <kbd>Ctrl Z</kbd> · 다시 실행 <kbd>Ctrl Shift Z</kbd>
- 빨간 ↻ **초기화**: 이 브라우저의 저장 안 된 초안을 모두 지우고 서버 상태로 돌아가요.
- 문서 제목 › 작업 이력 › **이 저장부터 되돌리기**: 예전 저장 시점으로 돌아가요.
