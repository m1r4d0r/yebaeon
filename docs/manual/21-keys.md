---
title: 단축키
group: 참고
lede: Mac은 Ctrl 대신 ⌘, Alt 대신 Option.
---

| 하는 일 | Windows | Mac |
|---|---|---|
| 서버 저장 | <kbd>Ctrl S</kbd> | <kbd>⌘ S</kbd> |
| 문서 검색 | <kbd>Ctrl F</kbd> | <kbd>⌘ F</kbd> |
| 실행취소 / 다시 실행 | <kbd>Ctrl Z</kbd> / <kbd>Ctrl Shift Z</kbd> | <kbd>⌘ Z</kbd> / <kbd>⌘ Shift Z</kbd> |
| 문서 열기·빠른 편집 | <kbd>Enter</kbd> | <kbd>Enter</kbd> |
| 닫기·선택 해제 | <kbd>Esc</kbd> | <kbd>Esc</kbd> |
| 리플로우 / 편집기 | <kbd>왼쪽 Alt R</kbd> / <kbd>E</kbd> | <kbd>왼쪽 Option R</kbd> / <kbd>E</kbd> |
| 성경 / 미디어 | <kbd>왼쪽 Alt B</kbd> / <kbd>V</kbd> | <kbd>왼쪽 Option B</kbd> / <kbd>V</kbd> |
| 슬라이드 복제 | <kbd>Ctrl D</kbd> | <kbd>⌘ D</kbd> |
| 이름 바꾸기 | <kbd>F2</kbd> | <kbd>F2</kbd> |
| 리플로우 장 나누기 | <kbd>Alt Enter</kbd> | <kbd>Option Enter</kbd> |
