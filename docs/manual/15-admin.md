> [!ADMIN]
> 이 묶음의 일은 관리자 비밀번호가 있어야 해요. 비밀번호는 서버 설정의 `ADMIN_PASSWORD`이고, 채팅이나 GitHub에 적지 않아요.

![관리자 확인 창](img/admin.png){small}

- 휴지통 비우기, 카테고리 설정, 교회 Mac 원격 명령처럼 되돌리기 어려운 일을 누르면 비밀번호 창이 떠요.
- 맞으면 **하루** 동안 다시 묻지 않아요(같은 입장에서만).
- 작업자 메뉴의 **관리자** 칩이 붙은 항목(교회 Mac, 설정·관리)은 열 때 비밀번호를 먼저 물어요.

## 설정·관리 창

| 칸 | 하는 일 |
|---|---|
| 문서 휴지통 | 휴지통 문서 목록, 하나씩 [[꺼내기]], [[비우기]](영구 삭제) |
| 재생목록 휴지통 | 휴지통 예배 목록과 [[비우기]]. 꺼내기는 [[휴지통 창]]에서 |
| 고아 이미지 | 슬라이드에서 가져온 그림(ImportedImages·YebaeOn) 중 어느 문서도 쓰지 않는 것. 골라서 [[고른 것 휴지통으로]] → 교회 Mac이 다음 [적용] 때 macOS 휴지통으로 옮겨요. 처음 한 번은 [[색인 채우기]]. 미디어 서랍(Images)은 처음 정리할 때만 [[Images 포함]]을 켜요 |
| 카테고리 | 카테고리마다 검색·이력 켜고 끄기 |
| 교회 Mac 보관본 | 양쪽에서 고쳐 서버 것을 받을 때 남긴 Mac 쪽 내용 받기, [[정리 끝]] |
| 검색 자료 | [[누락 검색 자료 점검]] |

위쪽 줄에 확인이 언제까지 유지되는지 보여요. [[관리자 확인 끝내기]]로 바로 끝낼 수 있어요.
- 비밀번호가 설정되지 않았으면 이 일들은 막혀 있어요.
