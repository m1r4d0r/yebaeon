## 이후 기능과 한계

1. **미디어 전송:** 현재는 경로/누락 점검과 웹의 로컬 연결까지다. 사용된 미디어 R2 업로드, 내려받기, 설치, 문서 경로 변환은 미구현이다. 새 미디어로 교체한 ZIP용 문서는 서버 문서 저장에서 차단한다.
2. **성경 자료:** 원본 전체 업로드·목록·해석·검색·슬라이드 생성은 후속 범위다. 파일 형식/번역본을 확인해야 한다.
3. **렌더 정밀도:** Windows 웹과 Mac PP6의 줄바꿈·폰트 크기·효과·이전 배경 유지 차이가 남는다. PP6 정상 화면과 대조할 자료가 필요하다.
4. **확장 편집:** 새 플레이리스트 생성/이름 변경/전체 삭제, 예배별 공유 문서 복사, 배열/전환/자동 실행 단서의 전문 편집은 후속이다. 현재는 기존 플레이리스트의 문서와 순서를 편집한다.
5. **충돌:** 양쪽 수정은 차단한다. 자동 병합/강제 덮어쓰기는 제공하지 않는다. 서버 등록은 같은 파일 이름·다른 내용이면 충돌로 표시한다. 공유 영향 표시는 같은 `.pro6pl` 파일 범위다.

## 웹 최근 사용일 표시

문서 목록·재생목록 문서 선택·현황판에 PP6 `lastDateUsed`를 한국시간으로 표시한다. 서버 저장일과 별도 표기하며 웹에서 열거나 저장한 시각으로 대체하지 않는다. 인증된 `/api/documents/:id/usage?version=N`은 해당 원본 버전의 앞 64KiB에서 루트 속성만 읽는다. 기존 자료 재업로드·원본 변경·스키마 변경은 필요 없다. 루트가 범위 안에 없으면 조회 실패로 표시한다. UI는 목록을 먼저 그리고 최대 4개씩 날짜를 읽으며 문서 ID/버전별로 페이지 내 캐시한다. 날짜 없음과 조회 실패를 구분한다. Mac 비교 API는 변경하지 않는다.

## 문서 라이브러리 전체 정렬과 현황판 진입

라이브러리에 이름순/이름 역순/PP6 최근 사용일/서버 저장 최신순 선택을 추가했다. 검색 결과 전체를 서버에서 정렬하고 날짜+경로 커서로 100개씩 이어 읽는다. 선택 기준은 브라우저에 저장한다. `yebaeon_document_usage`에 문서 ID·버전별 날짜를 UTC로 정규화해 저장하고 한국시간으로 표시한다. 새 원본 업로드 시 색인을 기록하며 기존 문서는 최근 사용일 정렬 최초 요청 시 12개씩(동시 4개) 수집하고 UI에 진행 수를 표시한다. 창 닫기/정렬 변경으로 후속 수집을 멈출 수 있고 이미 모은 날짜는 유지한다. 날짜 없는 문서와 조회 실패는 뒤쪽에 표시한다. 서버 현황판 링크는 상단뿐 아니라 문서/플레이리스트 대화상자 안에도 제공한다. 정렬·동일 시각의 페이지 경계·기존 원본 색인·한국시간 차이를 실제 Worker 시험으로 확인했다.

## 백업·초안 정책 구현 (Sync 0.4.2 build 7)

- 서버 현재 파일과 이전 버전은 계속 보존한다. 이력 자동 정리·예배별 아카이브·두 번째 백업 서비스는 추가하지 않았다.
- 문서 이력은 한국 날짜·작업자로 묶어서 펼친다. 이전 버전 복원은 현재 버전의 If-Match로 새 버전을 저장하며, 열린 편집 내용은 자동 교체하지 않는다.
- IndexedDB 초안은 문서 기준 버전·실제 원문·수정 내용, 순서 기준 계획·수정 배열을 보존한다. 페이지 인스턴스별 ID로 탭 충돌을 피한다. 복구 버튼에서 복사본으로 열며 기존 초안은 사용자가 정리한다. 저장 성공 시 해당 수정분만 정리하고, 저장 도중 새 수정은 저장된 내용을 기준으로 재설정한다. 충돌/통신 실패 시 유지한다. 새 교체 미디어 바이너리는 대상이 아니므로 ZIP 보관이 필요하다. 실제 브라우저 저장소 삭제/용량 제한을 백업으로 대체할 수 없다.
- 마지막으로 선택한 서버 재생목록을 다시 연다. 저장된 선택이 없거나 없어졌으면 서버 목록을 표시한다. 서버 원본 초기 가져오기 자체를 자동 수행하지는 않는다.
- 현황판 용량은 DB에 참조된 현재 문서/재생목록과 각각의 과거 버전을 구분한다. 정적 배포 이미지·폰트는 빌드 시 실제 파일 크기로 별도 집계한다. R2의 미참조 객체, DB, 과금량, Mac/브라우저 저장소 전체를 나타내지 않는다.
- 새 Mac 받기 작업은 완료된 작업 묶음 10회를 보관한다. 한 번에 여러 문서를 받아도 1회다. 실패한 묶음, 소유권 없는 구버전 백업은 제외하여 추가 보존한다. 중단된 문서/재생목록 복구가 필요한 동안 관련 정리를 보류한다. 완성된 묶음만 격리 이동 후 삭제하며 중단된 정리는 재시도한다. 자동 정리 실패는 동기화 성공과 별도로 알린다. 기존 개별 문서 복원과 재생목록 묶음 복원 UI를 유지한다.
- 웹 초안 검사는 비동기 저장소 모사에서 저장 도중 추가 편집, 문서 전환, 충돌, 용량 실패, 탭별 ID를 확인한다. 실제 브라우저 UI와 교회 High Sierra 실기는 별도로 확인해야 한다.

최종 검증: 웹 로컬·CI 30개 통과 및 배포 성공(`06bef0c`, 실행 36886891555). Mac 343개 검사와 0.4.2 build 7 패키지 생성 성공(`4e0521f`, 실행 36886825219). 기존 실행 중인 0.4.1 앱은 자동 교체되지 않는다. 웹 테스트 중간 실패·수정 내용과 실기 확인 한계는 CROSS-PLATFORM-LESSONS에 기록했다.
