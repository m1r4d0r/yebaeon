# 예배온 작업 인수인계 · 2026-10-01

새 세션은 이 문서와 [플레이리스트 작업 기준](PLAYLIST-WORKFLOW.md)을 먼저 읽는다. 완료 항목과 예정 항목을 구분하고 이미 한 문서 검사를 전체 플레이리스트 검증으로 오해하지 않는다.

## 목표

서버의 기존 플레이리스트 선택 → 안의 찬양/말씀 편집·저장 → 교회 Mac에서 해당 플레이리스트와 연결 문서를 동기화 → PP6에서 확인.

집 PC는 Windows, 교회 Mac은 High Sierra 10.13.6이다. 소스 수정과 푸시는 로컬 GitHub 클론에서 한다. GitHub 웹 로그인은 필요 없다.

## 다운로드와 소스

- 저장소: https://github.com/m1r4d0r/yebaeon (비공개)
- 준비한 배포 위치: https://github.com/m1r4d0r/yebaeon/releases/tag/v0.3.0
- `YebaeOn-Sync-macOS-v0.3.0.zip`: Intel Mac용 예배온 Sync 앱.
- `PP6-Playlist-Sync-Full-Dev-Bundle-2026-10-01-handoff.zip`: 커밋된 전체 소스, 제공받은 Native/Core/원본 자료 ZIP, 검증 앱, 인수인계. 실제 교회 자료가 포함되어 비공개 Releases에서 제공한다.
- `SHA256SUMS.txt`: 다운로드 무결성 확인값.

ZIP은 Git 소스 이력에 넣지 않고 Releases 첨부파일로 제공한다. `git pull`은 소스를 갱신하며 ZIP은 Releases에서 따로 내려받는다. 비공개 저장소 접근 권한으로 로그인해야 한다. 세션 비밀번호나 쿠키는 ZIP에 포함하지 않는다.

## 현재 빠진 핵심 기능 — 가장 먼저 이어갈 작업

**서버 플레이리스트 중심 흐름은 아직 미구현이다.** 현재 재생목록 탭은 로컬 `.pro6pl` 두 개의 비교·적용이고, 문서 탭은 `.pro6`를 수동 선택해 송수신한다. 탭을 통합한 것과 서버 플레이리스트 동기화는 다르다.

1. `.pro6pl` 원본/버전을 서버에 등록하고 파일 안의 플레이리스트들을 나누어 표시한다.
2. 순서 항목의 문서 경로를 서버 `.pro6` ID와 연결한다. 누락/중복을 표시하고 파일명만으로 자동 결정하지 않는다.
3. 웹 기본 화면을 플레이리스트 → 곡/말씀 → 기존 편집기 → 저장 흐름으로 연결한다.
4. Mac에서 플레이리스트 하나를 고르면 필요한 문서 변경까지 함께 수집·검증·백업·적용한다. `.pro6pl` 자체가 같아도 가사가 바뀌면 감지해야 한다.
5. 곡 추가/교체/순서 변경, 다른 플레이리스트 보존, 공유 문서 영향, 중간 실패·재개/복원을 검증한다.

제공 원본의 주 `.pro6pl`에는 플레이리스트 19개, 문서 항목 178개, 구분 항목 1개가 있다. 정규화한 고유 문서 참조 126개 중 23개는 여러 플레이리스트가 공유한다. 한글 분해형 경로와 `~/Documents/ProPresenter6/...` 경로에 주의한다. 문서 UUID도 원본/복사본 사이에 중복될 수 있다. 자세한 점검은 [PLAYLIST-WORKFLOW.md](PLAYLIST-WORKFLOW.md).

미디어 서버 전송/설치/경로 변환, 성경 원본 처리와 검색은 이후 범위다. 사용자가 이미 복사해 둔 폰트 폴더를 다시 수집하라고 요구하지 않는다.

## 교회 Mac에서 할 일

현재 0.3.0 앱은 별도 시험 폴더에서 실행·서버 로그인·문서 송수신·PP6 열기/저장까지 확인할 수 있다. 기존 앱은 삭제할 필요가 없다. 실행이 차단되면 Finder에서 우클릭 → 열기를 사용하며, 직접 빌드는 `mac-app/build.command`를 실행한다.

플레이리스트 기능이 추가된 후에는 서버의 플레이리스트 하나를 열어 가사 수정 → Mac에서 같은 플레이리스트 동기화 → PP6의 해당 순서에서 확인하는 실제 최종 흐름을 시험한다. 현재 앱으로 이 최종 흐름이 이미 된다고 안내하지 않는다.

## 개발 중 유지할 기준

- 새 기능은 집에서 서버/웹 검사와 Intel Mac 자동 검사를 마친 뒤 기본 브랜치로 올린다.
- 실제 교회 자료는 정적 사이트와 Git 소스에 넣지 않는다. 합성 자료로 자동 검사한다. 제공 원본은 비공개 전달 묶음에 보존한다.
- 자료 삭제·강제 덮어쓰기 없이 기준 버전 충돌을 표시한다. 서버 공용 비밀번호는 사용자만 알고 있으며 채팅·코드·로그에 넣지 않는다.
- 진행되는 대로 로컬 클론에서 커밋·푸시하고 이 문서의 완료/미완료 상태를 함께 갱신한다.
