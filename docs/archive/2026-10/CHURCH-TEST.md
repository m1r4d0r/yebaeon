# 교회 Mac에서 예배온 0.4.0 확인하기

목표는 **플레이리스트를 서버에 올리고, 웹에서 그 안의 곡을 수정한 뒤, Mac에서 같은 플레이리스트를 받아 PP6에서 확인**하는 것이다. 예전 Core 비교 검사를 다시 하는 과제가 아니다.

## 준비

[비공개 Releases](https://github.com/m1r4d0r/yebaeon/releases/tag/v0.4.0)에서 앱 ZIP을 내려받아 압축을 푼다. 기존 `PP6 Playlist Sync.app`과 백업은 보관한다. 새 앱 실행이 차단되면 Finder에서 우클릭 → 열기를 사용한다. 직접 빌드는 `mac-app/build.command`이며 내려받은 앱을 사용하면 빌드 도구·Node·Python이 필요 없다.

## 1. 실제 자료를 서버에 등록

1. PP6를 종료하고 **서버 재생목록** 탭에서 **입장 / 이름 변경**으로 이름과 공용 비밀번호를 입력한다. 브라우저 로그인과는 별도로 Mac 키체인에 세션을 저장한다.
2. **문서 폴더 선택**으로 실제 `.pro6` 라이브러리의 최상위 폴더를 고른다. 흔한 위치는 `~/Documents/ProPresenter6`이다.
3. **재생목록 파일 선택**으로 실제 `.pro6pl` 파일을 고른다. 이전 앱 설정이 있으면 경로를 이어받을 수 있다.
4. **원본 · 문서 서버 등록**을 누른다. 입력란은 재생목록이 원래 가리키던 문서 루트다. 일반적으로 `~/Documents/ProPresenter6`이며 실제 경로가 다르면 맞춘다.
5. 파일 안의 플레이리스트 전체와 참조 문서를 올린다. 같은 문서는 중복 저장하지 않고, 서버와 다른 내용이나 찾지 못한 경로는 결과에 남긴다. 원본 Mac 파일은 이 등록 단계에서 수정하지 않는다.

이 등록은 재생목록이 참조하는 문서부터 올린다. 라이브러리의 나머지 `.pro6`도 모두 올리려면 웹 **전체 문서 → 폴더 올리기** 또는 Mac **문서** 탭의 비교·선택 보내기를 사용한다. 미디어·성경 원본은 아직 이 업로드 대상이 아니다.

## 2. 시험 폴더에서 플레이리스트 받기

1. **시험 폴더**를 눌러 운영 Documents와 다른 폴더로 전환하고 **시험 파일 만들기**로 시험 `.pro6pl`을 만든다.
2. **서버 목록**에서 문서 수가 적은 플레이리스트 하나를 선택한다.
3. **선택 순서 비교**에서 누락/충돌 없이 연결되는지 확인한다. 공유 문서는 다른 예배에서도 쓰인다고 표시된다.
4. **이 플레이리스트 받기**로 문서와 순서를 함께 받는다. 파일명만 보고 임의로 연결하지 않으며 시험 재생목록의 참조는 선택한 시험 문서 폴더로 맞춰진다.

## 3. 웹 수정 → 같은 플레이리스트 동기화

집 PC 또는 최신 브라우저의 예배온 Studio에서 같은 플레이리스트를 열고 곡 하나를 수정·저장한다. Mac에서 다시 **선택 순서 비교**를 누른다. 재생목록 순서가 그대로여도 그 곡이 **받기**로 표시되어야 한다. **이 플레이리스트 받기** 후 시험 재생목록과 문서를 PP6에서 열어 순서·가사·줄바꿈·배경을 확인한다.

PP6가 시험 `.pro6pl`을 여는 방법이나 파일 형식에 문제가 있으면 그 화면/오류와 해당 파일의 구조를 다음 세션에서 확인한다. 현재 자동 검사는 파일 내용과 XML을 확인한 것이며 실제 PP6에서 시험 파일을 열어 본 결과는 아직 없다. 확인용으로 바꾼 가사는 웹에서 원래 내용으로 되돌려 다시 저장할 수 있다.

## 4. 막혔을 때

- **입장 실패:** 공용 비밀번호, 인터넷, Mac 날짜/시간을 확인한다. High Sierra에서 HTTPS나 키체인 오류가 나면 오류 문구를 기록한다.
- **문서 누락:** 선택한 문서 루트와 `.pro6pl` 안의 원래 경로가 맞는지 확인한다. 단순 파일명으로 억지 연결하지 않는다.
- **충돌:** 문서 탭의 내용 비교로 양쪽 수정을 확인한다. 자동 덮어쓰기는 하지 않는다.
- **동기화 중단:** 서버 재생목록 탭의 **백업 · 중단 복구**에서 해당 작업을 적용 전으로 복구하고, 다시 비교·받기한다. 중단 기록이 있으면 문서 탭의 별도 송수신도 차단한다.
- **화면 차이:** 정상 PP6 화면과 웹 미리보기의 같은 슬라이드를 비교한다. 폰트 폴더는 이미 보관해 두었으므로 다시 수집하지 않는다.

실제 운영 파일을 받을 때는 시험을 마친 뒤 **실제 문서 폴더와 실제 재생목록 파일을 다시 선택**해야 한다. 시험 폴더에 받은 결과가 운영 PP6에 자동 반영되는 것은 아니다.
