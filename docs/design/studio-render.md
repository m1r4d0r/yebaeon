# Studio 렌더링 설계

Studio가 PP6 문서를 화면에 그리고 편집할 때의 폰트·서식 해석 규칙과 확정 결정을 정한다. 웹 렌더는 PP6의 근사이며, 기능 검사 통과는 PP6와의 시각 일치를 뜻하지 않는다.

## 폰트

- 교회 Mac에서 받은 실제 폰트 원본을 `church-resources/`에 두고 서버가 제공한다. 외부 CDN의 동명 폰트로 대체하지 않는다. 브라우저는 FontFace로 서버 파일을 읽는다.
- 원본은 나눔고딕 OTF/TTF 14개(일반 Regular·Bold·ExtraBold·Light, Eco Regular·Bold·ExtraBold)와 아리따부리 OTF 5종(B·HL·L·M·SB)이다.
- 등록 이름은 파일 내부의 PostScript name이다. FontFace 식별자에 확장자를 포함해 OTF와 TTF가 충돌하지 않게 하고, family+Bold 이름을 먼저 조회한다.
- 굵기는 파일 메타데이터(`usWeightClass`)다. 나눔고딕 Bold는 600, ExtraBold는 700이다. 아리따부리 B·HL·L·M·SB는 700·300·400·500·600이다. 이름으로 굵기를 짐작하지 않는다.
- RTF의 폰트 이름이 Medium이어도 `b`(굵게)가 있으면 원본 Bold face를 고른다. 가짜 Bold나 중복 강조를 하지 않는다.
- 필요한 face만 불러온다(등록 45 face). 등록되지 않았거나 누락된 Bold는 근사 표시임을 알린다.
- 제공 원본 19개의 `hhea` ascent/descent를 catalog에 기록하고 그 값으로 조판한다. 그 밖의 폰트는 Canvas 메트릭을 쓴다.

## 원본 서식 해석

문서 크기는 1920×1080이다. 글상자 위치·크기는 `RVRect3D`의 position, 세로 정렬은 `verticalAlignment`, 문단 정렬·줄 간격·자간·글자 효과는 RTF에 저장된다.

- 글자 아웃라인은 RTF `strokewidth`/`strokec`에 저장되며 XML의 `drawingStroke`·shape stroke와 별개다. `drawingStroke=false`만으로 아웃라인 없음이라 판단하지 않는다. `strokewidth`는 20으로 나눈 값을 글자 크기 대비 백분율로 읽는다. 음수는 stroke+fill, 양수는 stroke만이다(−100 = −5%, 110pt에서 5.5 모델 단위).
- 줄 간격은 `slleading`을 20으로 나눈 값이다(460 → 23, −600 → −30). 자간은 `expnd`/`expndtw`(표지 제목의 `expndtw` −100은 자간 −5)이고 `kerning`도 읽는다. `sl`·`slmult` 등 다른 줄 높이 규칙은 처리하지 않는다.
- 음수 줄 간격을 기본 줄 높이에서 빼지 않는다. 원본 글꼴 메트릭의 줄 영역 하한을 유지한다(표지 제목 두 줄의 간격은 원본 PNG에서 약 119px이며, −30을 빼면 88.8px이 되어 맞지 않는다). 음수 값 자체는 편집값과 `.pro6`에 그대로 둔다.
- 그림자는 원본의 blur·색·offset을 읽는다. Native의 offset Y는 Canvas의 아래 방향 좌표로 바꾼다. OS별 blur 커널의 픽셀 일치는 범위 밖이다.
- 편집한 글상자의 RTF를 다시 쓸 때 자간·kerning·줄 간격·아웃라인과 문단 scalar controls 일부를 보존한다. 지원하지 않는 문단 조판은 경고하며, 모든 RTF 요소를 구현했다고 하지 않는다. 수정하지 않은 요소(XML 위치·그림자)는 그대로 둔다.

기준 서식(PP6 출력 PNG와 원본 `.pro6` 대조):

| 대상 | 폰트·크기 | 아웃라인 | 자간 | 줄 간격 | 위치·크기 |
|---|---|---:|---:|---:|---|
| 찬양 | NanumGothicOTF Bold 110 | 5 | 0 | 23 | −4,90 / 1929×899, 가운데 |
| 말씀 본문 | Arita-buri Bold 90 | 0 | 0 | 10 | 113,272 / 1693×683, 가운데 |
| 말씀 표지 제목 | Arita-buri Bold 99 | 0 | −5 | −30 | 415,316 / 1090×449, 가운데 |

말씀의 장절은 별도 글상자·별도 서식(크기 100, 줄 간격 20, 자간 −1)이므로 본문 서식을 일괄 적용하지 않는다. 말씀 본문의 그림자는 blur 19, 검정 알파 약 0.33, offset 0이다.

## 미리보기 구조

- 서버가 PNG 썸네일을 만들지 않는다. 브라우저가 문서 XML·RTF를 해석해 canvas에 직접 그린다.
- 공통 조판 결과를 최대 256개·추산 4 MiB로 캐시하고, 글꼴이나 자료가 바뀌면 무효화한다. 최종 canvas 캐시(32 MiB·256개)와 따로 둔다.
- 화면 크기는 CSS 크기×DPR(최대 3)이며 문서 해상도와 400만 픽셀 이내로 제한한다. 모든 슬라이드를 풀 해상도로 그리지 않는다.
- 보이지 않는 목록은 그리지 않는다. 열 수를 바꾸면 DOM과 원본 재파싱 없이 표시 canvas만 다시 그린다. 글꼴 로드 완료로 카드 DOM을 다시 만들지 않는다.
- 말씀의 줄 수 용량 계산은 같은 조판 결과를 쓰며 마지막 줄의 추가 간격을 제외한다.
- SVG 벡터 표시는 공통 조판 결과를 쓰더라도 PP6의 줄바꿈·폰트·효과 차이를 해결하지 않는다. Canvas와 SVG의 전환은 같은 곡·4~8열 조건의 계측 비교로 정한다.

## 편집 화면

- 일반 빠른 편집은 실제 서식을 반영한 슬라이드 미리보기와 텍스트 입력창을 나란히 둔다. 성경 빠른 편집과 방식을 통일한다.
- 슬라이드 목록의 한 줄 장수는 제목줄(문서 이력 왼쪽)의 슬라이더로 정한다. 4~8장의 정수 단계, 기본 6, 브라우저에 저장한다. 좁은 화면은 2열이다.
- 글상자 내용이 상자를 넘으면 중앙·하단 정렬의 음수 시작 위치를 0으로 제한하지 않고 그대로 그린다. 글상자의 원본 좌표와 높이는 고치지 않는다.
- 말씀 기본 템플릿은 카탈로그 ID 104(성경 · 설교 본문, Arita-buri 90pt, 우측 장절)다. 주변 슬라이드의 서식을 복제하지 않는다. 삽입할 때 다른 템플릿을 고를 수 있고 다음 삽입은 기본값으로 돌아온다. 같은 이름은 #ID와 해상도로 구분한다.
- 성경 본문은 가져올 때만 말단 공백·개행을 제거하고 내부 개행과 수동 줄바꿈은 보존한다.
- 저장 버튼 하나(‘변경사항 저장’)가 선택 재생목록의 수정 문서를 차례로 저장한 뒤 순서가 바뀌었으면 마지막에 순서를 저장한다. 서버 트랜잭션이 아니며 문서마다 CAS를 유지한다. 실패하면 그 지점에서 멈추고, 성공한 문서는 저장됨으로 처리하며 나머지는 초안에 보존한다. 재시도는 저장하지 않은 문서만 대상으로 한다.

## 공개 범위

PP6 출력 PNG, 원본 `.pro6`, 가사 fixture는 공개 빌드와 저장소에 넣지 않는다. 남은 렌더 정밀도(제목 슬라이드·자동 글자 크기·그림자)는 [BACKLOG](../BACKLOG.md)에서 관리한다.
