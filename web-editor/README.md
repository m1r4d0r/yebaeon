# 예배온 Studio

[사이트 열기](https://yebaeon.grace-jean-p.workers.dev/) · 대상은 Windows의 최신 Chrome/Edge다. 교회 Mac의 Sync가 문서와 재생목록을 서버에 올리고, Studio는 서버 자료를 편집한다. High Sierra Safari는 대상 브라우저가 아니다.

## 기본 흐름

1. 공용 비밀번호와 기록에 남길 작업자 이름으로 입장한다.
2. 왼쪽 문서 목록에서 검색·정렬하거나, 아래 재생목록의 순서에서 문서를 연다. 최근 사용일은 PP6 원본의 lastDateUsed이며 서버 저장일과 다르다.
3. 슬라이드 Enter는 빠른 편집, 더블클릭은 편집기다. 리플로우는 각 장의 첫 글상자를 나누고 합친다.
4. Ctrl+S로 문서를 서버에 저장한다. 순서 이동·추가·제거는 자동 저장한다. 충돌은 자동 덮어쓰기하지 않고 브라우저 초안에 보존한다.
5. 교회에서는 Sync로 받아 PP6에서 최종 확인한다.

문서 목록의 여러 항목을 순서에 끌거나 복사·붙여넣어 추가한다. 순서에서 Delete는 참조를 제거할 뿐 문서 파일을 삭제하지 않는다. 다른 예배에서도 쓰는 문서는 편집 내용이 함께 반영된다.

## 편집과 키보드

| 키 | 동작 |
|---|---|
| Ctrl+A / Ctrl·Shift 클릭 / Shift 방향키 | 현재 영역 전체·다중·범위 선택 |
| 방향키 / Home·End / PageUp·PageDown | 현재 목록이나 격자 탐색 |
| Enter / F2 / Delete | 열기·빠른 편집 / 슬라이드 이름 / 슬라이드·순서 항목 제거 |
| Ctrl+C·X·V / Ctrl+D | 선택 항목 복사·잘라내기·붙여넣기 / 선택 슬라이드 복제 |
| Ctrl+Z / Ctrl+Y·Shift+Z | 실행취소 / 다시실행 |
| Ctrl+S / Ctrl+F | 문서 서버 저장 / 문서 검색 |
| 왼쪽 Alt+R / E / B / V | 리플로우 / 편집기 / 말씀 / 미디어 |
| Alt+Enter / 본문 맨 앞 Backspace | 리플로우·말씀에서 나누기 / 앞 장과 합치기 |
| Shift+F10 / 메뉴 키 / Esc | 항목 메뉴 / 닫기·선택 해제 |

슬라이드 격자의 빈 곳을 누르면 선택이 풀린다(템플릿은 문서 전체에 적용). 슬라이드를 끌면 놓일 자리가 카드 사이 세로선과 `n번으로` 표시로 보이며, 마지막 카드 뒤나 아래 빈 곳에 놓으면 문서 끝으로 간다. 문서 복제는 문서 검색 결과·순서 항목의 우클릭 메뉴와 편집 화면 `⋯` 메뉴에 있고, 순서에서 복제하면 복제본을 원본 바로 뒤에 넣는다. 다른 문서를 열면 항상 슬라이드 보기로 시작한다.

글 입력 중 선택·클립보드·실행취소는 텍스트를 대상으로 한다. 한글 조합 중 키와 오른쪽 Alt는 전용 단축키로 처리하지 않는다. Alt+E가 브라우저 메뉴를 여는 환경에는 Alt+Shift+E 또는 더블클릭을 사용한다.

문서별 실행취소는 탭 안에서 50단계 유지한다. 전체 실행취소 자료가 200MiB를 넘으면 오래된 단계부터 제거한다. 서버에 저장하거나 문서를 다시 열어도 이력을 지우지 않는다. 순서 영역에서 실행취소하면 되돌린 순서도 자동 저장한다.

## 말씀·템플릿·미디어

말씀 입력 예: `요 3 16 4 2` → 요한복음 3:16–4:2, 23절. 장 전체, 한 절, 같은 장 범위도 입력할 수 있다. 템플릿의 실제 글꼴·본문 폭으로 줄바꿈하고 높이를 넘는 절은 균등하게 나눈다. 6줄 이상은 주황 표시한다. 직접 합친 장은 자동 재분할하지 않고 넘침을 표시한다. 말씀의 더블클릭/Enter는 빠른 편집이며 미리보기를 유지한다. 리플로우 전환으로 연속 본문과 각 장의 미리보기를 함께 수정한다. 본문은 첫 글상자, 장절은 둘째 글상자이며 슬라이드 이름에는 `(NKRV)`를 붙인다.

템플릿은 선택한 슬라이드에 적용하고 선택이 없으면 문서 전체에 적용한다. 미디어 서랍은 서버에 선별 등록된 교회 이미지다. 배경으로 적용해도 원래 Mac 경로를 유지한다. 로컬 파일 열기·업로드·ZIP/PNG 내보내기는 제공하지 않는다.

## 초안과 버전

이름 메뉴의 브라우저 초안에서 복구한다. 초안은 해당 브라우저에만 남고 서버 백업을 대신하지 않는다. 문서 머리줄은 문서 버전, 왼쪽 아래는 재생목록 **파일 전체**의 버전이다. 문서 복원은 기존 이력을 보존하며 새 현재 버전을 만든다. ‘내 작업 이력’은 현재 작업자 이름으로 저장한 기록이다.

## 확인과 한계

- `npm test`: 실제 Worker/D1/R2 모사, 저장 충돌·초안·이력·참조 수·말씀 규칙.
- `npm install --no-save --package-lock=false playwright@1.62.1` 후 `npx playwright install chromium`.
- `node web-editor/test-browser.cjs`: 합성 자료로 실제 Chromium UI 흐름 검사. 결과 화면은 `artifacts/`에 생성한다.
- `npm run deploy:check`: 운영 배포 전 번들 확인.
- GitHub `Verify Studio UX`는 브라우저 검사와 화면 산출물을 남긴다.

웹 렌더는 PP6의 근사치다. 교회 PP6의 말씀 캡처와 글꼴·줄바꿈을 대조하는 실기 확인은 별도다. 일반 편집기에서 글상자 추가·복제·삭제·이동·크기·레이어 순서와 선택한 글자의 폰트·크기·색·굵게·기울임·밑줄을 수정한다. 문단·세로 정렬과 줄 간격을 지원한다. 잠금은 현재 웹 편집 중의 보호이며 PP6 파일에 저장하지 않는다. 글상자 내용 수정과 리플로우 나누기·합치기는 해석 가능한 기존 서식 구간을 보존한다. 미지원 RTF 속성은 편집 시 재작성 대상이므로 PP6에서 확인해야 한다. 미디어 파일 전송과 새 재생목록 생성은 포함하지 않는다.



## 일반 편집기

슬라이드 더블클릭 또는 Alt+E로 연다. 왼쪽은 슬라이드 목록, 가운데는 큰 슬라이드 화면, 오른쪽은 레이어와 속성이다. 글상자를 드래그해 이동하고 오른쪽 아래 손잡이로 크기를 조절한다. 방향키는 1, Shift+방향키는 10 슬라이드 단위다. 회전된 글상자는 너비·높이 입력으로 크기를 조절한다. 1100px 이하 화면에서는 편집 화면 아래에 슬라이드 띠와 `‹ n / N ›` 버튼이 나오고, 화면을 좌우로 밀면 앞·다음 장으로 넘어간다. 터치에서는 글상자를 한 번 눌러 고른 뒤 끌어야 움직인다.

레이어 목록은 맨 앞부터 표시한다. 폰트·굵기 변종은 등록된 원본 이름과 아리따부리 별도 변종을 고른다. 본문 입력란에서 글자를 선택한 뒤 속성을 바꾸면 해당 부분에만 적용한다. 선택이 없으면 전체 글상자에 적용한다. 문단 정렬·추가 줄 간격은 선택한 문단 전체에 적용한다. 잠금은 현재 화면의 웹 편집 보호이며 문서 저장·재열기·실행취소 후에는 유지하지 않는다.

미리보기는 여전히 PP6 근사 렌더다. 폰트 읽기 실패·미등록과 글상자 높이 넘침을 표시한다. 자동 글자 크기, 자간·외곽선·정밀 그림자 및 미지원 요소의 전문 편집은 포함하지 않는다. 새 글상자는 기존 정상 글상자를 복제해 만든다. 문서 전체에 글상자가 없으면 텍스트 템플릿을 먼저 적용한다.
