# 예배온 Studio

[사이트 열기](https://yebaeon.grace-jean-p.workers.dev/) · 대상은 Windows의 최신 Chrome/Edge다. 교회 Mac의 Sync가 문서와 재생목록을 서버에 올리고, Studio는 서버 자료를 편집한다. High Sierra Safari는 대상 브라우저가 아니다.

## 기본 흐름

1. 공용 비밀번호와 기록에 남길 작업자 이름으로 입장한다.
2. 왼쪽 문서 목록에서 검색·정렬하거나, 아래 재생목록의 순서에서 문서를 연다. 최근 사용일은 PP6 원본의 lastDateUsed이며 서버 저장일과 다르다.
3. 슬라이드 Enter는 빠른 편집, 더블클릭은 편집기다. 리플로우는 각 장의 첫 글상자를 나누고 합친다.
4. Ctrl+S로 문서를 서버에 저장한다. 순서 이동·추가·제거는 자동 저장한다. 충돌은 자동 덮어쓰기하지 않고 브라우저 초안에 보존한다.
5. 교회에서는 Sync로 받아 PP6에서 최종 확인한다.

문서 검색 결과는 기본으로 관련성순이다: 이름이 검색어와 같음 → 이름이 검색어로 시작 → 이름에 포함 → 낱말이 모두 이름에 있음 → 본문에만 있음(이름의 띄어쓰기는 무시), 같은 단계는 최근 사용순. 왼쪽 검색창·주보 찬양 후보·PPT 교체 대상 검색은 같은 검색(`document-search.js`)을 각자 쓴다. 결과를 누르면 문서가 열리고, 순서에 넣는 것은 ＋ 버튼·손잡이 끌기·복사 붙여넣기만이다. 문서 목록의 여러 항목을 순서에 끌거나 복사·붙여넣어 추가한다. 순서에서 Delete는 참조를 제거할 뿐 문서 파일을 삭제하지 않는다. 다른 예배에서도 쓰는 문서는 편집 내용이 함께 반영된다.

## 편집과 키보드

| 키 | 동작 |
|---|---|
| Ctrl+A / Ctrl·Shift 클릭 / Shift 방향키 | 현재 영역 전체·다중·범위 선택 |
| 방향키 / Home·End / PageUp·PageDown | 현재 목록이나 격자 탐색 |
| Enter / F2 / Delete | 열기·빠른 편집 / 슬라이드 이름 / 슬라이드·순서 항목 제거 |
| Ctrl+C·X·V / Ctrl+D | 선택 항목 복사·잘라내기·붙여넣기 / 선택 슬라이드 복제 |
| Ctrl+Z / Ctrl+Y·Shift+Z | 실행취소 / 다시실행 |
| Ctrl+S / Ctrl+F | 문서 서버 저장 / 문서 검색 |
| 왼쪽 Alt+R / E / B / V | 리플로우 / 편집기 / 말씀 / 미디어 |
| Alt+Enter / 본문 맨 앞 Backspace | 리플로우·말씀에서 나누기 / 앞 장과 합치기 |
| Shift+F10 / 메뉴 키 / Esc | 항목 메뉴 / 닫기·선택 해제 |

슬라이드 격자의 빈 곳을 누르면 선택이 풀린다(템플릿은 문서 전체에 적용). 슬라이드를 끌면 놓일 자리가 카드 사이 세로선과 `n번으로` 표시로 보이며, 마지막 카드 뒤나 아래 빈 곳에 놓으면 문서 끝으로 간다. 휴대폰·태블릿에서는 카드를 잠깐(0.3초) 누르고 있다가 끌면 옮겨지고, 바로 밀면 스크롤된다. 누르고만 있다 떼면 슬라이드 메뉴가 열린다. 문서 복제는 문서 검색 결과·순서 항목의 우클릭 메뉴와 편집 화면 `⋯` 메뉴에 있고, 순서에서 복제하면 복제본을 원본 바로 뒤에 넣는다. 다른 문서를 열면 항상 슬라이드 보기로 시작한다.

글 입력 중 선택·클립보드·실행취소는 텍스트를 대상으로 한다. 한글 조합 중 키와 오른쪽 Alt는 전용 단축키로 처리하지 않는다. Alt+E가 브라우저 메뉴를 여는 환경에는 Alt+Shift+E 또는 더블클릭을 사용한다.

문서별 실행취소는 탭 안에서 50단계 유지한다. 전체 실행취소 자료가 200MiB를 넘으면 오래된 단계부터 제거한다. 서버에 저장하거나 문서를 다시 열어도 이력을 지우지 않는다. 순서 영역에서 실행취소하면 되돌린 순서도 자동 저장한다.

## 말씀·템플릿·미디어

말씀 입력 예: `요 3 16 4 2` → 요한복음 3:16–4:2, 23절. 장 전체, 한 절, 같은 장 범위도 입력할 수 있다. 템플릿의 실제 글꼴·본문 폭으로 줄바꿈하고 높이를 넘는 절은 균등하게 나눈다. 6줄 이상은 주황 표시한다. 직접 합친 장은 자동 재분할하지 않고 넘침을 표시한다. 말씀의 더블클릭/Enter는 빠른 편집이며 미리보기를 유지한다. 리플로우 전환으로 연속 본문과 각 장의 미리보기를 함께 수정한다. 본문은 첫 글상자, 장절은 둘째 글상자이며 슬라이드 이름에는 `(NKRV)`를 붙인다.

템플릿은 선택한 슬라이드에 적용하고 선택이 없으면 문서 전체에 적용한다. 미디어 서랍은 서버에 선별 등록된 교회 이미지다. 배경으로 적용해도 원래 Mac 경로를 유지한다. 로컬 파일 열기·업로드·ZIP/PNG 내보내기는 제공하지 않는다.

## 영광임하소서 목록

작업자 메뉴 `작업` 묶음의 `영광임하소서 목록`으로 연다. 누구나 볼 수 있고, 관리 단추([목록 붙여넣기]·[짝 붙여넣기]·[곡 추가]·[고르기]·`⋯`)는 관리자 확인(설정·관리 창에서 하루 유지)일 때만 보인다. 규칙과 저장 방식은 [문서 정리 정책](../docs/design/library-policy.md#영광임하소서-목록과-권장-버전)에 있다.

- 검색칸은 번호·검색어·연결 문서 이름으로 거른다. 옆의 [전체 n | 확인 필요 n | 문서 없음 n]으로 볼 곡을 고른다. 확인 필요는 이름이 같은 곡으로 보이는 사용 중 찬양 문서(연결·아님·다른 곡 연결이 아닌 것)가 있는 곡이고, 그 줄에 '후보 n'이 붙는다. 문서 없음은 연결 문서가 하나도 없는 곡이다.
- 표: 번호(조) | 검색어(첫 줄 진하게) | 가사찬양 | 악보찬양. 문서 칸은 연결 문서 이름이며 휴지통·보관함 문서는 흐리게 표시한다.
- [고르기]: 후보와 문서 검색(본문 포함)에서 골라 [연결] 또는 [아님]. 가사·악보는 문서 카테고리를 따르고, 가사찬양·악보찬양 문서만 연결할 수 있다. 연결된 문서는 [연결 빼기], 아님으로 둔 문서는 [아님 취소].
- [고르기] 창의 줄마다 이름 아래 내용 미리보기: 가사찬양은 첫 가사 두 줄(제목뿐인 장은 건너뜀), 악보찬양·글 없는 문서는 첫 악보 장의 작은 그림. 누르면 앞 장 4장까지 줄 아래에 펼치고 다시 누르면 접는다. 창에 보이는 줄의 문서만 창이 열려 있는 동안 한 번씩 받는다. 읽지 못하면 '미리보기 없음'.
- `⋯`: 검색어 고치기(번호·조도 함께), 연결 빼기, 곡 지우기(문서는 그대로).
- [목록 붙여넣기]: 탭으로 나뉜 글(UTF-8, 한 줄에 한 곡)을 붙여 넣으면 미리보기(곡 수·연결 수, 새로·바뀜·빠짐, 휴지통·보관함 연결 수)와 오류(서버에 없는 id, 찬양이 아닌 카테고리 연결, 한 문서 두 곡 연결, 번호 겹침 등)를 보인다. 오류가 없을 때만 [저장]이 켜지고 목록 전체를 바꾼다.

```text
번호<TAB>조<TAB>검색어(/로 구분)<TAB>연결 문서 id(,로 구분)<TAB>아님 문서 id(,로 구분)
```

첫 줄이 `번호`로 시작하면 머리줄로 건너뛴다. 뒤 두 칸은 비어도 된다. 다른 관리자가 먼저 바꿨으면 저장이 거절되고 최신 목록을 다시 읽는다.

- [짝 붙여넣기]: 목록 밖 곡의 가사·악보 짝 전체를 바꾼다. 한 줄에 한 짝, 문서 id를 쉼표로 나눈다(UTF-8). 탭 뒤는 메모라 무시하고, 빈 줄과 `#`로 시작하는 줄은 건너뛴다. 미리보기는 짝 수·문서 수, 새로·바뀜·빠짐과 줄마다 오류(없는 문서, 찬양 아닌 문서, 목록 곡 문서, 두 짝에 들어간 문서, 가사·악보 한쪽만)를 보이고, 오류가 없을 때만 [저장]이 켜진다.

```text
# 메모 줄
가사 문서 id,악보 문서 id<TAB>곡 이름 메모
```

검색 결과(왼쪽 검색창·주보 찬양 후보·PPT 교체 대상)의 카테고리 칩은 두 글자(가사·악보·예배·특별)이고 마우스를 올리면 전체 이름이 보인다. 찬양은 칩과 행 바탕을 가사찬양 청록, 악보찬양 주황으로 칠하고, 목록에 연결된 문서는 이름 옆에 `영 58`처럼 번호가 붙는다. 재생목록 순서도 찬양 행을 같은 색으로 칠하고 머리줄 오른쪽에 같은 색 네모로 범례를 둔다. 영광임하소서에 없는 곡의 가사 행에는 [악보로](같은 곡 악보로 바꾸고 바로 저장) 또는 [악보 필요](안내 창에서 [PPT 가져오기]로 악보 만들기, 가사로 쓰는 곡이면 [예외 처리])가 붙는다. 예외 처리는 순서 항목 메뉴의 '예외 처리 해제'로 되돌린다. 순서 항목 메뉴의 '악보로 바꾸기'·'가사로 바꾸기'는 바꿀 같은 곡 문서가 있을 때만 켜진다. 이름이 달라 짝을 못 찾는 곡은 메뉴 '짝 고르기…'에서 문서를 검색해(가사 문서면 악보만, 악보 문서면 가사만 보임) [짝으로]로 묶고 [빼기]로 푼다(누구나). 저장된 짝은 검색에도 쓰여, 가사찬양 결과 바로 다음에 짝 악보가 붙고 결과에 없던 악보에는 이름 옆에 회색 '가사로 찾음'이 붙는다(왼쪽 검색창·주보 찬양 후보). PPT 가져오기로 새 악보찬양을 만들 때는 '짝 찬양' 줄에 이름으로 찾은 가사가 '자동 추천'으로 뜨고, [짝으로]를 눌러야 문서를 추가할 때 짝으로 저장된다([다른 찬양…]으로 직접 고름, 이미 악보 짝이 있으면 옛 악보를 뺄지 고름). PPT 교체 대상 검색에는 가사찬양 행이 나오지 않지만, 가사로 찾은 짝 악보는 '가사로 찾음'을 달고 나온다.

## 초안과 버전

`작업 이력`(작업자 메뉴)은 날짜별 한 줄 목록이다. 줄마다 [바뀐 것]은 그 저장 바로 전 버전과 슬라이드를 나란히 비교하고(예배 순서는 항목 비교), ⋯ › `이 저장부터 되돌리기`를 누르면, 그 저장과 목록에서 그 위(뒤)의 저장이 건드린 문서·예배 순서를 그 가운데 가장 앞선 저장 바로 전 버전으로 되돌린다. 버전을 지우지 않고 새 버전으로 남기므로 다시 되돌릴 수 있다. `모든 작업자`에서 고르면 다른 작업자의 저장도 함께 되돌린다. 상단 빨간 ↻(초기화)는 확인 창 한 번 뒤 이 브라우저의 모든 문서·순서 초안을 지우고 화면을 새로 불러온다. 서버 저장본은 그대로다. 이름 메뉴의 브라우저 초안에서 복구한다. 초안은 해당 브라우저에만 남고 서버 백업을 대신하지 않는다. 문서 머리줄은 문서 버전, 왼쪽 아래는 재생목록 **파일 전체**의 버전이다. 문서 복원은 기존 이력을 보존하며 새 현재 버전을 만든다. 저장 이력의 [현재와 비교]는 고른 버전과 현재를 같은 비교 창으로 보여 준다. ‘작업 이력’의 `내 것`은 현재 작업자 이름으로 저장한 기록이다.

## 확인과 한계

- `npm test`: 실제 Worker/D1/R2 모사, 저장 충돌·초안·이력·참조 수·말씀 규칙.
- `npm install --no-save --package-lock=false playwright@1.62.1` 후 `npx playwright install chromium`.
- `node web-editor/test-browser.cjs`: 합성 자료로 실제 Chromium UI 흐름 검사. 결과 화면은 `artifacts/`에 생성한다.
- `npm run deploy:check`: 운영 배포 전 번들 확인.
- GitHub `Verify Studio UX`는 브라우저 검사와 화면 산출물을 남긴다.

웹 렌더는 PP6의 근사치다. 교회 PP6의 말씀 캡처와 글꼴·줄바꿈을 대조하는 실기 확인은 별도다. 일반 편집기에서 글상자 추가·복제·삭제·이동·크기·레이어 순서와 선택한 글자의 폰트·크기·색·굵게·기울임·밑줄을 수정한다. 문단·세로 정렬과 줄 간격을 지원한다. 잠금은 현재 웹 편집 중의 보호이며 PP6 파일에 저장하지 않는다. 글상자 내용 수정과 리플로우 나누기·합치기는 해석 가능한 기존 서식 구간을 보존한다. 미지원 RTF 속성은 편집 시 재작성 대상이므로 PP6에서 확인해야 한다. 미디어 파일 전송과 새 재생목록 생성은 포함하지 않는다.



## 일반 편집기

슬라이드 더블클릭 또는 Alt+E로 연다. 왼쪽은 슬라이드 목록, 가운데는 큰 슬라이드 화면, 오른쪽은 레이어와 속성이다. 글상자를 드래그해 이동하고 오른쪽 아래 손잡이로 크기를 조절한다. 방향키는 1, Shift+방향키는 10 슬라이드 단위다. 회전된 글상자는 너비·높이 입력으로 크기를 조절한다. 1100px 이하 화면에서는 편집 화면 아래에 슬라이드 띠와 `‹ n / N ›` 버튼이 나오고, 화면을 좌우로 밀면 앞·다음 장으로 넘어간다. 터치에서는 글상자를 한 번 눌러 고른 뒤 끌어야 움직인다.

레이어 목록은 맨 앞부터 표시한다. 폰트·굵기 변종은 등록된 원본 이름과 아리따부리 별도 변종을 고른다. 본문 입력란에서 글자를 선택한 뒤 속성을 바꾸면 해당 부분에만 적용한다. 선택이 없으면 전체 글상자에 적용한다. 문단 정렬·추가 줄 간격은 선택한 문단 전체에 적용한다. 잠금은 현재 화면의 웹 편집 보호이며 문서 저장·재열기·실행취소 후에는 유지하지 않는다.

미리보기는 여전히 PP6 근사 렌더다. 폰트 읽기 실패·미등록과 글상자 높이 넘침을 표시한다. 자동 글자 크기, 자간·외곽선·정밀 그림자 및 미지원 요소의 전문 편집은 포함하지 않는다. 새 글상자는 기존 정상 글상자를 복제해 만든다. 문서 전체에 글상자가 없으면 텍스트 템플릿을 먼저 적용한다.
